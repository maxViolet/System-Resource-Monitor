# First-release evidence and self-contained publication package

- [Brick brief](../B07-first-release.md): scope, dependencies, acceptance criteria, and exclusions.
- [Implementation plan](plan.md): ordered work, artifact identity, release gates, and evidence handoff.
- Evidence: add separate dated automated, Windows integration, and manual desktop/resource reports under `docs/acceptance/`, as the delivery roadmap requires; the implementation plan explains this B07 choice and links the gates.

The brick brief and its linked product plan, implementation plan, and ADRs remain authoritative. Package files may make the work executable for coding agents, but must not silently change scope or acceptance criteria.
