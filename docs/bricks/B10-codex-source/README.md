# Qualify a Codex limit source package

- [Brick brief](../B10-codex-source.md): scope, dependencies, acceptance criteria, and exclusions.
- [Implementation plan](plan.md): ordered qualification steps, gates, and the handoff to B012.
- Evidence: the dated qualification report at `docs/research/providers/codex-<YYYY-MM-DD>.md`, as the brick brief requires.

The brick brief and its linked product plan, implementation plan, and ADRs remain authoritative. Package files may make the work executable for coding agents, but must not silently change scope or acceptance criteria.
