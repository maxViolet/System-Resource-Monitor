# B015.2 - Visual redesign from the approved mockup

Status: in progress. Owner: B015. Recorded: 2026-11-17.

## Sources and scope

- [B015 brief](../B15-bar-redesign.md) and [package](README.md); [B015.1](B15.1-three-region-layout.md) is its baseline.
- [Product plan — Shared bar design](../../plan.md#shared-bar-design) and [Implementation plan — Shared bar redesign](../../implementation-plan.md#shared-bar-redesign).
- The approved mockup is the [HTML prototype](../../../prototype/task-strip-design.html). [ADR 0029](../../adr/0029-secondary-colour-for-metric-labels.md) records the one difference between its "Current" state and the measured bar: the `CPU`, `RAM`, and `GPU` labels are drawn in `#9FACBC`.

Apply that colour. Everything else the mockup shows belongs to B019 and B020. The three regions, live scale change, AppBar lifecycle, fullscreen and Explorer-recovery behavior, non-activating pointer behavior, native tray actions, section text, tooltips, and fixed widths from B015.1 stay in force.

## Implementation work

1. Record the decision in ADR 0029.
2. Draw each system-metric label as a separate run in `#9FACBC` and the rest of the section in `#E6E6E6`. Desktop only.
3. Extend `--metric-display` to check both colours and the full section text in every display state.
4. Run the automated verification, then compare a published-app crop with the mockup and with the B015.1 bounds.

## Acceptance criteria

- [ ] ADR 0029 is accepted, and the product plan names the label colour
- [ ] In every display state, the `CPU`, `RAM`, and `GPU` labels render in `#9FACBC`, the rest of the section in `#E6E6E6`, and the section text and tooltip are unchanged (`--metric-display`)
- [ ] The published bar at 125% shows the new label colour in a redacted crop, and its section bounds equal the B015.1 bounds
- [ ] Locked restore, Release build, full solution tests, and self-contained publish pass on the source commit

## Out of scope

Task buttons, overflow, keyboard task access, and the clock belong to B019. The in-bar tray, shell indicators, and hiding the Windows taskbar belong to B020. Everything the [B015 brief](../B15-bar-redesign.md#out-of-scope) excludes stays excluded.
