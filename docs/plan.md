# План: System Resource Monitor

Термины записаны в [CONTEXT.md](../CONTEXT.md); решение о размещении — в [ADR 0001](adr/0001-separate-windows-appbar.md).

## Требования

- Windows 11; сначала личное использование, позднее возможна публикация.
- Тонкая тёмная панель на всю ширину основного монитора по предоставленному образцу.
- Верхнее положение либо нижнее над системной панелью задач; панель резервирует место и скрывается на время полноэкранного приложения.
- На панели: загрузка и температура CPU/GPU, занятость RAM, для Codex и Claude по два остатка лимита в порядке `короткий%/недельный%`.
- При наведении на подписку: времена сброса обоих окон. Недоступный датчик показывает прочерк; ошибка источника лимитов показывает `--/--` и объяснение.
- Системные показатели обновляются раз в 2 секунды, лимиты — раз в минуту.
- Автозапуск при входе в Windows можно отключить.

## 1. Проверить источники лимитов — блокирующий технический опыт для секций подписок

- На уже авторизованных Codex CLI и Claude Code найти воспроизводимый локальный способ получить короткий и недельный **остатки**, а также времена их сброса.
- Зафиксировать версию клиента, способ вызова, формат ответа, ограничения и поведение при выходе из учётной записи. Не сохранять секреты и не читать браузерные cookies.
- Успех для каждого провайдера: два последовательных опроса без интерактивного ввода дают оба окна и времена сброса; ошибка входа или сети различима и не превращается в старое значение.
- Если проверка не проходит, оставить соответствующую секцию недоступной. Это не блокирует выпуск системной панели.

## 2. Сделать оболочку панели — блокирующий этап первого выпуска

- Окно на всю ширину основного монитора регистрируется как AppBar и занимает согласованную с Windows полосу.
- Настройка переключает верхнее положение и нижнее положение над системной панелью задач.
- На реальном Windows 11 проверить запуск, закрытие, перезапуск Explorer, смену положения, смену разрешения и масштаба. После закрытия приложения рабочая область восстанавливается.
- При полноэкранном приложении панель скрывается и возвращается после выхода. Проверить это вручную с видео и игрой или другим полноэкранным приложением.

## 3. Добавить системные показатели — блокирующий этап первого выпуска

- Каждые 2 секунды обновлять загрузку и температуру CPU/GPU, занятость RAM.
- Для отсутствующего датчика показывать прочерк и сохранять остальные работающие показатели.
- На целевом ПК сверить значения с независимым системным инструментом при простое и под нагрузкой; зафиксировать модель CPU/GPU и недоступные датчики. Точные допуски сравнения определить после выбора источника показаний.

## 4. Добавить отображение лимитов — условный этап

- Для каждого сервиса на полосе показывать `короткий%/недельный%`; при наведении — оба времени сброса.
- Опрос раз в минуту. При ошибке показывать `--/--` и объяснение без выдачи старых данных за текущие.
- Приёмка на подписке: значения и времена сброса совпадают с отображаемыми официальным клиентом в одном временном окне проверки; после потери доступа появляется состояние ошибки. Это ручная проверка, отдельная от модульных тестов разбора данных.

## 5. Подготовить личное использование и публикацию

- Добавить включаемый/отключаемый запуск при входе в Windows и выход из приложения с освобождением AppBar.
- Документировать установку, ограничения датчиков и лимитов, а также сценарий отключения автозапуска.
- Перед публикацией проверить запуск на чистом профиле Windows 11 без авторизации в Codex/Claude: системная панель работает, секции подписок явно недоступны.

## Правило выпуска

Первый выпуск требует пройденных этапов 2, 3 и 5. Этап 1 является воротами только для соответствующей подписочной секции этапа 4. Непроверенные лимиты не отображаются как достоверные.
