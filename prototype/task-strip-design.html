Current bar

CPU, RAM, GPU, Codex, and Claude sections reflect the checked desktop code. Its separate native tray icon owns position and exit; future task, clock, and in-bar tray features are not active.

Task behavior

Each task is a 32 DIP icon. The real bar will use the window icon, or a neutral fallback. Hover for the full title; overflow lists titles and marks a hidden active task.

Phase boundary

B017 keeps the Windows taskbar available. B018 hides it only after tray recovery is proven and restores it if the replacement tray fails.
