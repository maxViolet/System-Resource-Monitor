# System resource package

Place platform-independent system metric values, monitoring policy, and source contracts here as B05–B06 and later metric bricks are implemented. CPU and RAM readings remain independent; later GPU and temperature work belongs here only after its brick is accepted. Keep native readers and other Windows APIs in Desktop.

This directory is a source package within the existing Core project, not a separate assembly. Use valid C# namespaces; the directory's hyphenated name is not a namespace segment.
