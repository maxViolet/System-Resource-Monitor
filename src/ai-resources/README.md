# AI resources package

This package owns the separate Core project for qualified Codex and Claude subscription limit values, policy, and source contracts. Do not add provider behavior before B10 or B11 qualifies its source. Future concrete AI source adapters belong under this package; the system-resources Desktop application will compose accepted adapters at its entry point.

The package is not a separate application. No credentials, raw account output, or undocumented provider endpoints belong in the repository.
