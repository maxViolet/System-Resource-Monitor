# AI resources package

This package owns the separate Core project for qualified Codex and Claude subscription limit values, policy, and source contracts. Do not add provider behavior before B010 or B012 qualifies its source, respectively. B011 implements the accepted Codex source; B013 implements Claude only if B012 accepts it. Future concrete AI source adapters belong under this package; the system-resources Desktop application will compose accepted adapters at its entry point.

The package is not a separate application. No credentials, raw account output, or undocumented provider endpoints belong in the repository.
